# Feature map — portfolio

User-facing features worth proving. Each file is the maintained verification
source for that feature: what it is, how a user reaches it, how to drive it
with the headless-Chrome harness, and gotchas.

- [navigation](navigation.md) — fixed top nav, anchor scrolling, Projects dropdown, mobile menu
- [hero](hero.md) — first impression, headline, View My Work / Get In Touch CTAs
- [work-projects](work-projects.md) — Work Experience cards, achievements, Let's Connect CTA
- [personal-projects](personal-projects.md) — project grid, status badges, GitHub / Live Demo buttons
- [contact](contact.md) — connect banner, email + blog actions, footer, 404 fallback

Coverage rule: a proof that drives one convenient entry point is incomplete
when this index lists others. Drive the mapped feature file, not a shortcut.
